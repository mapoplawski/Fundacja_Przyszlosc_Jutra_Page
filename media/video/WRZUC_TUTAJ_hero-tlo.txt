INSTRUKCJA WIDEO W TLE STRONY GŁÓWNEJ (GitHub Pages)
====================================================
1. Zapisz docelowy plik wideo w tym folderze dokładnie pod nazwą:
   hero-tlo.mp4

2. Zalecane parametry pod hosting GitHub Pages:
   - Format: MP4 (kodek H.264 / AVC)
   - Rozdzielczość: 1920x1080 (Full HD) lub 1280x720 (HD)
   - Czas trwania: pętla 10–25 sekund
   - Ścieżka dźwiękowa: usunięta (wideo w tle i tak jest wyciszone — oszczędza 15-25% wagi pliku)
   - Waga pliku: najlepiej 4–15 MB (twardy limit pojedynczego pliku na GitHubie to 100 MB; powyżej 50 MB GitHub wyświetla ostrzeżenie).

3. Dopóki plik hero-tlo.mp4 nie zostanie wgrany, strona automatycznie wyświetla statyczny obraz posterowy:
   media/img/hero/strona-glowna-poster.webp
