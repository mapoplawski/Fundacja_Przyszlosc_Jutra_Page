# Fundacja Przeszłość Jutra — Serwis Internetowy

Kompletna, responsywna witryna internetowa Fundacji Przeszłość Jutra przygotowana zgodnie z makietami i wytycznymi projektowymi (`Projekt strony.xlsx` oraz `wizualizacje`).

## Struktura projektu
- `index.html` — Strona główna (wideo/baner otwierający, misja, obszary działania, 3 główne inicjatywy, współpraca, aktualności, wezwanie do działania)
- `o-fundacji.html` — O fundacji (dlaczego powstaliśmy, 3 filary: Zachować / Rozumieć / Uczestniczyć, cele w praktyce, założyciel i prezes Igor Czapczyk wraz z pełnym biogramem, informacje formalne KRS/NIP/REGON)
- `projekty.html` — Projekty (katalog 3 głównych projektów, projekt wyróżniony o por. Janie Nowickim „Rysiu”, szczegółowe podstrony projektów w formie dedykowanych sekcji/widoków)
- `aktualnosci.html` — Aktualności (wyróżniona aktualność z 25 września 2026 r., filtrowanie po kategoriach, wyszukiwarka wpisów, pełne podglądy artykułów i galeria)
- `wspolpraca.html` — Współpraca (grupy partnerów, formy współpracy, projekty partnerskie, logotypy partnerów, interaktywny formularz współpracy)
- `wesprzyj-nas.html` — Wesprzyj nas (formy wsparcia, dane do przelewu z funkcją kopiowania numeru rachunku jednym kliknięciem, zaangażowanie pozafinansowe)
- `kontakt.html` — Kontakt (dane kontaktowe, adres siedziby, social media, formularz kontaktowy z wyborem tematu)
- `polityka-prywatnosci.html` — Polityka prywatności i informacja o przetwarzaniu danych osobowych (RODO)
- `css/style.css` — Arkusz stylów (szlachetna paleta kremowo-burgundowo-antracytowa, typografia szeryfowa i bezszeryfowa, responsywność)
- `js/main.js` — Obsługa nawigacji mobilnej, filtrowania aktualności, wyszukiwarki, kopiowania numeru konta, modali artykułów/projektów oraz formularzy

## Publikacja na GitHub Pages
1. Wgraj zawartość folderu do repozytorium GitHub.
2. Wejdź w **Settings → Pages**.
3. Wybierz źródło **Deploy from a branch** (`main` / `root`).
4. Zapisz — strona będzie dostępna pod adresem GitHub Pages.
